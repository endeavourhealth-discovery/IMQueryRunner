# Run Queries
This specification describes the query running functionality of IMQueryRunner.

## Run Registered GMS
* Open IMQueryRunner
* Login
* Click "Run a query" button
* Search for "http://endhealth.info/im#Q_RegisteredGMS" and select "Patients registered for GMS services on the reference date"
* Click "Add to queue" button
* Click "Run queue" button
* Click "Select" button
* Wait "20" seconds
* Click "Refresh" button
* Open results page
* Check total results equal "6479"
* Click "Back to queue" button
